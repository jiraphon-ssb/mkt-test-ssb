# Runbook — ข้อมูลโฆษณาไม่เข้า ทำยังไง

> สำหรับทีม SSB · อัปเดต 16 ก.ย. 2569 · หน้าที่ใช้ตรวจคือ **สถานะ Sync** (`/mkt/ads/sync`)

## ตรวจ 3 อย่างนี้ตามลำดับ

### 1. ตัวดึงอัตโนมัติยังวิ่งอยู่ไหม

ดูกล่อง **"ดึงอัตโนมัติ"** บนหน้าสถานะ Sync

| ป้าย | แปลว่า | ทำอะไร |
|---|---|---|
| ทำงานปกติ | มีรอบภายใน 2 ชั่วโมงที่ผ่านมา | ไม่ต้องทำอะไร |
| เงียบเกินกำหนด | ไม่มีรอบเลยเกิน 2 ชั่วโมง | ตัวตั้งเวลาในฐานข้อมูลหยุด — ดูหัวข้อ "ตัวตั้งเวลาไม่ทำงาน" |
| รอบล่าสุดไม่สำเร็จ / ค้างกลางทาง | รอบล่าสุดพังหรือถูกตัดกลางคัน | ดูคอลัมน์ "ผล" ในตารางว่าเป็น error อะไร แล้วเทียบตารางด้านล่าง |
| ยังไม่เริ่มทำงาน | ยังไม่เคยมีรอบเลย | ยังไม่ได้ตั้งค่า Vault (ดูท้ายไฟล์) |

### 2. แต่ละบัญชีสถานะอะไร

ตาราง **"บัญชีที่ต้องดู"** เรียงบัญชีที่ต้องแก้ไว้บนสุด

| error ที่เห็น | แปลว่า | ทำอะไร |
|---|---|---|
| `META_TOKEN_EXPIRING` | การเชื่อม Meta ใกล้หมดอายุ (เตือนล่วงหน้า 7 วัน) | ไปหน้าตั้งค่า → กด "เชื่อมบัญชี" ใหม่ ใช้เวลาไม่ถึงนาที |
| `META_TOKEN_INVALID` | หมดอายุแล้ว หรือถูกถอนสิทธิ์ | เชื่อมใหม่เหมือนกัน · ระหว่างนี้บัญชีนั้นจะถูกข้ามในรอบอัตโนมัติ (บัญชีอื่นยังดึงตามปกติ) |
| `META_RATE_LIMIT` | Meta จำกัดปริมาณชั่วคราว | ไม่ต้องทำอะไร รอบถัดไปจะดึงต่อเอง |
| `SYNC_EMPTY_RESULT` | Meta ตอบว่าไม่มีข้อมูลทั้งที่เคยมี — ระบบกันไม่ให้เขียนทับของเดิม | ไม่ต้องทำอะไร ถ้าขึ้นติดกันหลายวันให้แจ้งอาร์ต |
| `META_TOO_MUCH_DATA` | ช่วงวันที่ขอใหญ่เกินสำหรับบัญชีนั้น | กด "ดึงข้อมูลตอนนี้" เพื่อไล่ทีละก้อนเล็กลง |
| `AUTHORIZATION_NOT_READY` | คนที่เชื่อมบัญชีไว้ถูกปิดสิทธิ์/ออกจากทีม | ให้หัวหน้าทีมเชื่อมบัญชีใหม่ |

### 3. ข้อมูลครบหรือยัง

ดูคอลัมน์ **"ช่องว่าง"** — ถ้ามีตัวเลขวันค้าง ระบบจะทยอยเติมเองชั่วโมงละ 4 ก้อน หรือกด **"ดึงข้อมูลตอนนี้"** ให้จบเร็วขึ้น (หัวหน้าทีมเท่านั้น)

## ตัวเลขไม่ตรงกับ Ads Manager

กด **"ตรวจยอด"** บนหน้าสถานะ Sync — ระบบจะเทียบค่าแอด 7 วันและ 30 วัน (จบเมื่อวาน) กับ Meta โดยตรง แล้วบอกว่าต่างกี่เปอร์เซ็นต์

ถ้าต่างเกินเกณฑ์ ให้ดูว่า

1. วันที่เทียบมีช่องว่างไหม (ข้อ 3 ด้านบน) — ข้อมูลไม่ครบก็ไม่มีทางตรง
2. ตัวเลขที่ดูเป็น "วันนี้" หรือเปล่า — ยอดวันนี้ยังไม่ปิด Meta แก้ย้อนหลังได้ถึง 3 วัน
3. ยอดขาย/ROAS บนหน้าเว็บคือค่าที่ **Meta attribute** ไม่ใช่ยอดขายจริงจากระบบขาย (กล่อง "ยอดขายจริง" จะขึ้นเมื่อเชื่อมระบบขายแล้ว)

## ตัวตั้งเวลาไม่ทำงาน

ตรวจตามลำดับ (ต้องใช้สิทธิ์ Supabase)

```sql
-- 1. job ยังอยู่และเปิดอยู่ไหม
select jobname, schedule, active from cron.job where jobname = 'ads-sync-tick';

-- 2. ยิงทดสอบเดี๋ยวนั้น แล้วดูผล
select ads_ops.cron_tick();
select status_code, left(content, 300) from net._http_response order by id desc limit 1;

-- 3. ความลับใน Vault ยังอยู่ไหม (ไม่มี = tick จะข้ามเงียบๆ)
select name from vault.secrets where name in ('ads_cron_url', 'ads_cron_key');
```

ผลที่ควรได้จากข้อ 2 คือ `status_code = 200` และ content มี `"status":"success"`

## ค่าที่ต้องตั้งไว้ (ตั้งครั้งเดียว)

| ที่ไหน | ชื่อ | ใช้ทำอะไร |
|---|---|---|
| Supabase → Vault | `ads_cron_url`, `ads_cron_key` | ให้ pg_cron เรียก Edge Function ได้ |
| Supabase → Edge Functions → Secrets | `META_APP_ID`, `META_APP_SECRET`, `META_OAUTH_REDIRECT_URI`, `ADS_TOKEN_ENCRYPTION_KEY`, `ADS_APP_ORIGIN`, `ADS_ALLOWED_ORIGINS` | เชื่อม Meta และเข้ารหัส token |
| Supabase → Edge Functions → Secrets | `SALES_API_URL`, `SALES_API_KEY` | ดึงยอดขายจริงจากระบบขาย (ยังไม่ตั้ง = ข้ามเงียบๆ ไม่พัง) |
| Vercel → Environment | `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`, `VITE_AUTH_MODE=supabase` | ให้เว็บต่อฐานข้อมูลและบังคับล็อกอิน |
