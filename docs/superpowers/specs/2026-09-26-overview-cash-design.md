## แบบ

### 1. ตัวเลข (`salesOverview.js`)

- `salesFactsByBrand` เพิ่ม `cancelledValue`, `refunds` และ `cashTracked` (true เมื่อมีแถวที่ source ≠ `tmk` — ระบบ TMK ไม่มีเงินเข้า/มัดจำ ส่งมาเป็น 0)
- ฟังก์ชันใหม่ `cashSummary({ sales, brands, spendById, names })`:
  - ต่อแบรนด์: `{ tracked, cash, deposits, depositValue, revenue (gross), gap = cash − revenue, cashPerSpend = cash ÷ spend, cancelled, cancelledValue, refunds }` · ไม่ tracked = ตัวเลขเงินเข้า/มัดจำเป็น null แต่ยกเลิก/คืนยังนับ
  - รวม: รวมเฉพาะแบรนด์ที่ tracked (spend ก็รวมเฉพาะแบรนด์นั้น) · `excluded` = ชื่อแบรนด์ที่มียอดขายแต่ไม่ tracked
- `overviewModel` คืน `cash: { overall, byBrand }` เมื่อเป็นข้อมูลจริง (ข้อมูลตัวอย่าง = null ไม่แสดงกล่อง)

### 2. กล่อง "เงินจริง" (มุมเดือน · `AdsWorkspace`)

- ต่อจากกล่องงบโฆษณา Meta (แถวกลางของหน้าเรียงกล่องลงทีละกล่องอยู่แล้ว — ตามโครงเดิม)
- หัว: "เงินจริง" + ป้ายสั้น "ไม่รวม X" เมื่อมี excluded (มุมรวม)
- ตัวใหญ่: เงินเข้าแล้ว ฿X
- บรรทัดเทียบยอดขาย (ยอดรวม ไม่ขึ้นกับปุ่มคิดจากยอดใหม่): gap < 0 → "ยังเก็บเงินไม่ครบ ฿|gap|" (สีเตือน) · gap > 0 → "เงินเข้าเกินยอดขาย ฿gap · รวมมัดจำงานที่ยังไม่ปิด" · 0 → "เท่ายอดขาย"
- รายการ: มัดจำ (N ราย) · มูลค่ามัดจำ · เงินเข้าต่อค่าแอด (x)
- ยกเลิก/คืนเงิน: บรรทัดเดียวเฉพาะเมื่อ cancelled > 0 หรือ cancelledValue > 0 หรือ refunds > 0 — "ยกเลิก N รายการ · ฿V" (+ " · คืนเงิน ฿R" เมื่อ > 0)
- มุมแบรนด์ที่ไม่ tracked: "ระบบ TMK ไม่มีข้อมูลเงินเข้าและมัดจำ" (+ บรรทัดยกเลิกถ้ามี)
- ตารางแบรนด์: คอลัมน์ "เงินเข้า" หลัง "ยอดขาย / เป้า" · ไม่ tracked = "—"

### 3. เชิงอรรถที่เดียว — "สูตรและที่มา" ท้ายหน้า (พับไว้)

- ย้ายเข้า: ขีดบนแถบ (ราง + ตาราง) · แบรนด์ที่ไม่รวมในยอดรวม/เป้ารวม (พร้อมเหตุผล) · ที่มาของ funnel ที่ไม่รวม JUNTAKARN · "สูตรที่ใช้" (ROAS · %Ads) + สูตรเงินเข้าต่อค่าแอด · หมายเหตุที่มาของกราฟแนวโน้ม
- คงในหน้า: ข้อความเตือนสถานะข้อมูล (เช่น "ค่าแอดมีถึง … ยังตัดสินจังหวะงบไม่ได้") · ป้ายสั้น "ไม่รวม X" ข้างหัวตัวเลขรวม

### 4. สถานะโหลด

- ข้อมูลจริงกำลังโหลด → พื้นที่เนื้อหาขึ้น "กำลังโหลดตัวเลข…" แทน hero/กล่อง/ตาราง
