## ปัญหา

หน้า ads คิด ROAS จากมูลค่า purchase ที่ Meta attribute ซึ่งพิสูจน์แล้วว่าไม่ใช่ยอดจริงของธุรกิจ — 16 ก.ย. 2026 JUNTAKARN ปิดการขาย 183 ครั้ง แต่ Meta รู้มูลค่าแค่ 26,952 บาท (เฉลี่ย 147 บาท/ออเดอร์) เพราะปิดการขายทางแชท Meta จึงไม่รู้ราคา

ยอดจริงอยู่ในโปรเจกต์ขาย `fofgbjmpmywaldkfhtkx` (repo `ssbgroup-platform`) ตาราง `sale_deal`

## การตัดสินใจ

| เรื่อง | ตัดสินใจ |
|---|---|
| ทิศทาง | ดึงมาอย่างเดียว ไม่ส่งค่าแอดกลับไป (ทีมขายยังนำเข้า CSV เองตามเดิม) |
| นิยามรายได้ | `revenue_recognized_date` = วันจ่ายงวดแรก + `sale_revenue_correction.delta` ลงวันที่แก้ — ตรงกับ P&L ที่พี่ทัชดู |
| ไม่นับ | ดีลที่ `confirm_reverted` (ถอนยืนยัน) · ดีลที่ยังไม่มี `recognized_amount` |
| ประตูฝั่งขาย | ฟังก์ชัน `mkt_revenue_daily(from, to)` อ่านอย่างเดียว คืนแค่ brand · day · revenue · orders · เรียกได้เฉพาะ service_role — **พี่ทัชรีวิวและรันเอง** (ไฟล์: `docs/handoff/sales-revenue-bridge.sql`) |
| ข้อมูลที่ไหลข้ามระบบ | ตัวเลขรวมรายวันเท่านั้น ไม่มีชื่อ/เบอร์/ที่อยู่/รายการสินค้า |
| เก็บที่ไหน | `business_daily_facts` (มีอยู่แล้ว) `source='crm'` · `external_record_id = '<brand>|<day>'` |
| ความถี่ | วันละครั้งผ่าน cron ที่มีอยู่ · ดึงย้อนหลัง 14 วันทุกครั้ง เพราะยอดปรับย้อนหลังได้ |
| คีย์ | ตั้งเป็น Edge Function secret ของ marketing: `SALES_API_URL` · `SALES_API_KEY` (อาร์ตใส่เองผ่าน Dashboard → Edge Functions → Secrets) · ยังไม่ตั้ง = `sales-sync` ข้ามเงียบๆ ไม่ error |
| แบรนด์ | TD→b_td · JD→b_jk (JK Design) · TA→b_ta · JK→b_jt (JUNTAKARN) · SF ยังไม่มีในระบบ ads = ข้าม |
| การแสดงผล | ยอดขายจริงและ ROAS จริงเป็นตัวหลัก · ค่าที่ Meta attribute ยังแสดงคู่กันแต่ติดป้ายว่าคนละนิยาม · แบรนด์/วันที่ยังไม่มีข้อมูล = "—" ไม่ใช่ ฿0 |

## ไม่ทำรอบนี้

funnel เทียบ (คนทัก/ลีด/มัดจำ) · เป้าจาก `sale_goal` · ROAS ระดับแคมเปญ (ต้องให้ระบบขายเก็บ ref จาก ctwa ก่อน) · ส่งค่าแอดกลับไปที่ `mkt_spend`

## เกณฑ์ผ่าน

- เทส pure ครอบ: แปลงรหัสแบรนด์ · รวม correction เข้ากับวันเดิม · ดึงซ้ำแล้วทับไม่บวกเพิ่ม · null ≠ 0 · ช่วงวันเกิน 400 วันถูกตัด
- เทียบยอดรวมเดือน ก.ย. กับหน้าจอระบบขายของพี่ทัชแล้วตรง
- หน้า ads แสดง ROAS จริงพร้อมป้ายที่มา และแบรนด์ที่ยังไม่มีข้อมูลไม่กลายเป็น 0
