# หน้า Creative — จัดลำดับข้อมูลใหม่ (งานย่อย 1/3)

วันที่: 2026-09-26 · สถานะ: อาร์ตอนุมัติแบบในแชทแล้ว รอตรวจสเปก
งานย่อยถัดไป: 2) หน้าแคมเปญ (เพิ่มชุดโฆษณา) · 3) หน้าภาพรวม (เงินเข้า มัดจำ ยกเลิก/คืนเงิน) — แต่ละงานมีสเปกของตัวเอง

## ที่มา

อาร์ตแจ้งว่า UI/UX ยังใช้ไม่ได้ เพราะข้อมูลที่จำเป็นไม่ถูกดึงขึ้นมา แต่ของไม่จำเป็น (เช่นแคปชั่น) กลับอยู่บนหน้าหลัก
ผลสำรวจโค้ดและข้อมูลจริง (26 ก.ย.) ที่เกี่ยวกับหน้านี้:

- การ์ดครีเอทีฟโชว์แคปชั่น 2 บรรทัดทุกใบ ([CreativeCard.jsx:36](../../../src/modules/marketing/creatives/CreativeCard.jsx))
- ROAS ของชิ้นทักแชทขึ้น 0.00x สีแดง เพราะ revenue เริ่มที่ 0 ไม่ใช่ null ([adsOverview.js:739](../../../src/modules/marketing/adsOverview.js)) ส่วนหน้าแคมเปญซ่อนไว้ สองหน้าจึงพูดไม่ตรงกัน
- CTR ใช้คลิกทั้งหมด (`clicks`) ทั้งที่มี `link_clicks` โหลดมาแล้ว ([adsFacts.js:98](../../../src/modules/marketing/ads/adsFacts.js)) แต่ไม่มีที่ไหนแสดง
- ชื่อชุดโฆษณา (`ad_group`) โหลดมาแล้ว ([adsFacts.js:83](../../../src/modules/marketing/ads/adsFacts.js)) แต่ไม่มีที่ไหนแสดง
- แถบที่มาข้อมูลขึ้นทุกหน้าทุกวัน ทั้งที่ส่วนใหญ่บอกแค่ "ทุกแหล่งสดและครบ" + "วันนี้ยังไม่สิ้นสุด"
- เชิงอรรถยาวใต้ตารางเทียบรูปแบบ และบรรทัดเทคนิค "จะมากับรอบดึงตี 5" ในหน้าต่างครีเอทีฟ

## แบบ

### 1. การ์ดครีเอทีฟ (`CreativeCard`)

บนลงล่าง:
1. ภาพ + ป้ายรูปแบบ (เหมือนเดิม)
2. ชื่อ (2 บรรทัด) + ป้ายคำแนะนำ (น่าขยาย / ควรแก้ / ควรหยุด / เริ่มล้า)
3. จุดสถานะ — เฉพาะเมื่อรู้สถานะ (เหมือนเดิม)
4. **ตัวเลข 4 ช่อง คงที่ทุกใบ: ค่าแอด · ต่อผลลัพธ์ · CTR ลิงก์ · ROAS**
   - ต่อผลลัพธ์ = ค่าแอด ÷ ผลลัพธ์ Meta (`cpl`) · ไม่มีผลลัพธ์ = "—"
   - CTR ลิงก์ = `linkCtr` (ข้อ 2)
   - ROAS = "—" สีเทา เมื่อ Meta ไม่เห็นการซื้อ · สีแดงเฉพาะเมื่อมีการซื้อจริงแต่ ROAS < 1
5. ผลกฎ (เมื่อเปิดกฎ)
6. ท้าย: "อยู่ใน N แคมเปญ" · ลิงก์ FB/IG · ช่องติ๊กเทียบ
- **ไม่มีแคปชั่น** — ข้อความโฆษณาอยู่ในหน้าต่างครีเอทีฟเท่านั้น

### 2. ตัวเลขชุดเดียวกันทุกที่ (`adsCreativeRows`)

- เพิ่มฟิลด์ต่อชิ้นและต่อแคมเปญ (`perCampaign`): `linkClicks`, `linkCtr` (= linkClicks ÷ impressions), `linkCpc` (= spend ÷ linkClicks)
  - การ์ดที่ไม่มี `link_clicks` เลย → `linkClicks` เป็น null (ห้ามเดาจาก clicks)
- ROAS ของชิ้นและต่อแคมเปญ: Meta ไม่เห็นยอดเลย (ไม่มีการซื้อ **และ** รายได้เป็น 0/ไม่รู้) → `roas: null`
  - ผลตามมา: คำแนะนำของชิ้นทักแชทจะไม่ขึ้น "ควรหยุด" จาก ROAS 0 อีก (ตัดสินจาก CPL/ความล้าแทน)
  - กฎเดียวกันใช้กับการ์ด ตาราง หน้าต่าง และบรรทัด ROAS ในหน้าแคมเปญ
- **ไม่เปลี่ยน**: `ctr` (คลิกทั้งหมด) ยังเป็นฐานของกฎเริ่มล้าและกฎคัดครีเอทีฟที่อาร์ตตั้งไว้ — ไม่เปลี่ยนความหมายกฎเดิม

### 3. ตารางครีเอทีฟ (`CreativeTable`)

- คอลัมน์ CTR → CTR ลิงก์ · ROAS ใช้กฎ "—" ข้อ 2 · คอลัมน์อื่นเหมือนเดิม

### 4. หน้าต่างครีเอทีฟ (`CreativeViewer`)

- กลุ่มการเข้าถึง: เพิ่ม **คลิกลิงก์ · CTR ลิงก์ · CPC ลิงก์** · CTR ทั้งหมดยังอยู่ (เป็นฐานกฎเริ่มล้า)
- ตาราง "อยู่ใน N แคมเปญ": ชื่อชุดโฆษณาเป็นบรรทัดรองใต้ชื่อแคมเปญ (หลายชุด = คั่นด้วย ·) · คอลัมน์ CTR → CTR ลิงก์
- เอาบรรทัด "ยังไม่มีสถานะจาก Meta · จะมากับรอบดึงตี 5" ออก — ไม่รู้สถานะ = ไม่ขึ้นป้ายสถานะ (ตามหลักเดิม)
- แคปชั่นเต็ม + "อ่านทั้งหมด" คงเดิม (ที่เดียวที่มีแคปชั่น)

### 5. แถบที่มาข้อมูล (`AdsSourceNotice` — ใช้ร่วมทั้ง 3 หน้า)

- สถานะ `ok` (ทุกแหล่งสดและครบ) → **ไม่แสดงแถบ**
- ขึ้นเฉพาะ: กำลังโหลด · โหลดพัง · ยังไม่มีค่าแอดจริง · แหล่งค้าง/ไม่ครบ (`warn`) · ยังไม่มีแหล่ง (`muted`)
- "วันนี้ยังไม่สิ้นสุด ยอดยังเปลี่ยนได้" → ขึ้นเฉพาะเมื่อช่วงที่เลือกเป็นวันนี้วันเดียว (ส่ง prop จากหน้า)
- รายละเอียดตอนปกติ → หน้าสถานะ Sync (มีอยู่แล้ว)

### 6. เชิงอรรถ → "สูตรและที่มา"

- ท้ายหน้า Creative มี `<details>` พับไว้ชื่อ "สูตรและที่มา" รวม: คำอธิบายรูปแบบชิ้นงาน (เดิมใต้ตารางเทียบรูปแบบ) · CTR ลิงก์ vs CTR ทั้งหมด · ROAS "—" · สถานะมาจากรอบดึง 05:00
- ตารางเทียบรูปแบบไม่มีเชิงอรรถใต้ตารางอีก

### 7. บั๊กที่แก้ก่อน (งานเล็กแยก · commit แยก)

- หน้าภาพรวม: ตัวแปร `st` ไม่มีอยู่ในการ์ดช่องทาง → กด "ดูรายละเอียด" แล้วหน้าพัง ([AdsView.jsx:263](../../../src/modules/marketing/ads/AdsView.jsx))
- แผงแคมเปญ: "ข้อมูลจำลองจากการ์ดรายวัน" ขึ้นแม้เป็นข้อมูลจริง ([CampaignDetail.jsx:98](../../../src/modules/marketing/campaigns/CampaignDetail.jsx))
