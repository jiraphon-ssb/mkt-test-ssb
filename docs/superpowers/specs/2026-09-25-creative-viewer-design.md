# หน้าต่างครีเอทีฟตัวเดียว + รายการครีเอทีฟตามพื้นที่ (ทาง A)

วันที่ 25 ก.ย. 2569 · อาร์ตเคาะทาง A · แทนที่ "ตารางครีเอทีฟกลาง" ของ v0.14.0 ที่อาร์ตบอกว่าใช้งานยาก

## ปัญหาที่ต้องแก้ (เห็นจริงบนข้อมูลจริง 25 ก.ย.)

1. **popup ซ้อน** — คลิกแถว → หน้าต่างดูเต็ม → ในหน้าต่างนั้นรูปทั้งกรอบเป็นปุ่ม "ตัวอย่างจาก Meta" แตะรูปจึงเด้งหน้าต่างที่สองทับ · มุมมองการ์ดเดิมคลิกรูปก็เด้งหน้าต่าง Meta ทันที
2. **รายการอยู่ล่างสุดของจอ** — ตัวกรอง 2 แถว · กล่องกฎ · สรุปผลกฎ (+ "แก้กฎ" ลอยซ้ำ) · ตารางรูปแบบ · การ์ดสรุป 5 ใบ ดันรายการลงไป ปุ่มสลับ ตาราง/การ์ด จมหาย
3. **ตารางอ่านยาก** — ช่องชื่อจัดวางเพี้ยน (td เป็น flex) · ผลกฎเป็นแถบสีเต็มแถว · สถานะพูดซ้ำ 2 บรรทัด · รูปย่อ 44px ดูไม่ออก · การ์ดลอยตอนชี้เด้งไปมา
4. **แผงแคมเปญ** — ตารางรูปจิ๋วในแผงแคบ เสียจุดเด่นที่เห็นชิ้นงานชัด
5. **ขาดข้อมูลรายแคมเปญ** — ชิ้นเดียวกันยิงหลายแคมเปญถูกรวมการ์ดอยู่แล้ว (144 โพสต์) แต่กดเข้าไปไม่รู้ว่าแต่ละแคมเปญได้เท่าไร และเปิด/ปิดอยู่

## การตัดสินใจ (อาร์ตตอบ 25 ก.ย.)

| เรื่อง | เลือก |
|---|---|
| คลิกครีเอทีฟ | หน้าต่างเดียว มีแท็บ [ภาพและข้อมูล] [ตัวอย่างจาก Meta] · ‹ › ไปชิ้นก่อน/ถัดไป |
| หน้าคลังเปิดมา | **รูปเต็ม (การ์ดแบบเดิม)** · สลับ รูป/ตาราง ได้ |
| ในหน้าต่าง | ต้องบอก **อยู่ในแคมเปญไหน · แต่ละแคมเปญได้ค่าอะไร · แคมเปญนั้นเปิด/ปิด** |
| แผงแคมเปญ | รายการกะทัดรัด รูป 72px |
| ส่วนบนหน้าคลัง | ยุบเหลือแถบเดียว |
| รวมการ์ด | ชิ้นงานเดียวกันหลายแคมเปญ = การ์ดเดียว (รวมด้วยรหัสโพสต์ — ทำอยู่แล้ว) · **15 กรณีชื่อซ้ำแต่คนละโพสต์ ไม่รวม** (อาร์ตยังไม่ตอบ — ค่าที่ปลอดภัย ตัวเลขไม่ปน) |

## ข้อห้าม (จากปัญหาข้างบน)

- ไม่มีหน้าต่างเด้งซ้อนกันในทุกเส้นทาง — ตัวอย่างจาก Meta เป็นแท็บ ไม่ใช่หน้าต่างใหม่
- รูปในรายการและในหน้าต่าง: คลิกรูป = เลื่อนภาพ/เปิดหน้าต่างของชิ้นนั้น ไม่เปิดอย่างอื่น
- ไม่มีการ์ดลอยตอนชี้เมาส์
- ตัวเลข: เงิน 2 ตำแหน่งตัดไม่ปัด · ไม่รู้ = "—" ไม่ใช่ 0 · สถานะไม่รู้ = "ไม่ทราบสถานะ" ไม่เดา

## ส่วนประกอบ

### 1. ข้อมูลรายแคมเปญ — `adsCreativeRows` (src/modules/marketing/adsOverview.js)

ระหว่างรวมยอดต่อชิ้น เก็บยอดแยกตามชื่อแคมเปญเพิ่ม แล้วคืน `row.perCampaign`:

```js
perCampaign: [{ campaign, spend, leads, cpl, ctr, roas, purchases, status /* effective_status ของโฆษณาชิ้นนี้ในแคมเปญนั้น */ }]
// เรียงค่าแอดมากก่อน · Σ spend ของทุกแถว = row.spend (เทสคุม)
```

สถานะแคมเปญ (เปิด/ปิด) คิดตอนแสดงจาก `perCampaign[].status` ของ **ทุกชิ้น** ในแคมเปญเดียวกัน (`campaignStatusOf` เดิม) — ฟังก์ชันใหม่ `campaignStatusIndex(rows)` → `Map<ชื่อแคมเปญ, สถานะ>` ใน creativeStatus.js

### 2. `CreativeViewer.jsx` — หน้าต่างเดียว (แทน CreativeDetail + CreativePreview ที่เปิดแยก)

- props: `rows` (ลำดับที่แสดงอยู่), `index`, `onIndex(i)`, `onClose`, `canPreview`, `campaignStatus: Map`
- หัว: แบรนด์ · ชื่อชิ้นงาน · `‹ 3/221 ›` (ปุ่ม + ลูกศรซ้าย/ขวาบนคีย์บอร์ด) · ✕ · Esc ปิด
- แท็บ **ภาพและข้อมูล**: CreativeMedia โหมด `inline` (คลิกรูป = ภาพถัดไป ไม่มีปุ่มเปิดตัวอย่างทับรูป) · สถานะโฆษณา + เวลาที่อ่านจาก Meta · ตัวเลขรวม · คำแนะนำ + เหตุผล · ข้อความโฆษณาเต็ม · ลิงก์โพสต์ FB/IG
- ส่วน **อยู่ใน N แคมเปญ**: ตารางย่อยแถวละแคมเปญ — ชื่อแคมเปญ (ลิงก์ไปหน้าแคมเปญ + เปิดแผงของแคมเปญนั้น) · สถานะแคมเปญ · สถานะชิ้นนี้ในแคมเปญ · ค่าแอด · ผลลัพธ์ · CTR · ROAS
- แท็บ **ตัวอย่างจาก Meta**: เนื้อในของ CreativePreview ปัจจุบัน (เลือกตำแหน่งแสดง + iframe) ย้ายมาเป็น component ภายใน `MetaPreviewPane` — ไม่มีฉากหลัง/หน้าต่างของตัวเอง · แท็บนี้ซ่อนเมื่อดูตัวอย่างไม่ได้
- มือถือ: หน้าต่างเต็มจอ รูปอยู่บน ข้อมูลอยู่ล่าง

### 3. หน้าคลัง Creative (CreativeLibraryView.jsx)

- **เปิดมาเป็นรูปเต็มเสมอ (`view=cards`)** · ปุ่ม [รูป | ตาราง] ย้ายขึ้นหัวหน้า ข้างปุ่มตั้งค่า · เลือกตารางแล้วอยู่ในลิงก์ (`?view=table`) ส่งต่อ/กดย้อนกลับได้ · ไม่จำข้ามการเปิดหน้าใหม่ (อาร์ตเลือก "แสดงแบบเต็มมา")
- ส่วนบน: ตัวกรองแถวเดียว (ตัวกรองรองพับอยู่แล้ว) → **แถบสรุป 1 บรรทัด** (ชิ้นงาน · ค่าแอด · การซื้อ · เริ่มล้า) → **ชิปผลกฎ** กดกรอง (ไม่ผ่าน/ผ่าน/ยังตัดสินไม่ได้) + ลิงก์ "แก้กฎ" ที่เดียว → "เทียบตามรูปแบบชิ้นงาน" เป็น `<details>` พับ · ถอดกล่องรายการกฎและการ์ดสรุป 5 ใบ
- การ์ด: หน้าตาเดิม + จุดสถานะเปิด/ปิดมุมการ์ด · คลิกที่ไหนก็ได้บนการ์ด (รวมรูป) = CreativeViewer · ช่องติ๊ก "เทียบ" ยังทำงานแยก
- ตาราง (`CreativeTable` รื้อ): รูป 56px · ชื่อชิดซ้าย 2 บรรทัด (td ปกติ ไม่ใช่ flex) · สถานะบรรทัดเดียว · ผลกฎเป็นป้ายเล็กท้ายชื่อ · เลิก HoverCard · คลิกแถว = CreativeViewer

### 4. แผงแคมเปญ (CampaignDetail.jsx)

- `CreativeList` ใหม่ (รายการกะทัดรัด): รูป 72px · ชื่อ 2 บรรทัด + รูปแบบ · สถานะ · ค่าแอด/ROAS · ป้ายคำแนะนำ · คลิก = CreativeViewer (ส่วน "อยู่ในแคมเปญ" ไฮไลต์แคมเปญนี้)

### 5. ลิงก์ไปเปิดแคมเปญ

- `/mkt/campaigns?open=<ชื่อแคมเปญ>` → CampaignsTable เปิดแผงของแคมเปญที่ชื่อตรงเมื่อโหลดหน้า (ไม่เจอ = เงียบ ไม่ error)

## ถอดของเดิม

- `CreativeDetail.jsx` → แทนด้วย CreativeViewer · `HoverCard` ใน CreativeTable → ถอด
- CreativePreview แบบหน้าต่างแยก → เหลือเป็น MetaPreviewPane ภายใน viewer (โค้ดเรียก ads-preview และตรวจ src เดิมคงไว้ทั้งหมด)

## การทดสอบ

- `adsCreativeRows`: perCampaign แยกถูก · Σ spend = row.spend · สถานะต่อแคมเปญมาจากโฆษณาในแคมเปญนั้น
- `campaignStatusIndex`: แคมเปญที่มีชิ้นเปิด = เปิดอยู่ · ไม่รู้ = ไม่ทราบ
- CreativeViewer: เปิดแล้วมี `role=dialog` ตัวเดียวเสมอ (รวมหลังกดแท็บ Meta และหลังคลิกรูป) · ‹ › และลูกศรเปลี่ยนชิ้น · Esc ปิด · แท็บ Meta ซ่อนเมื่อดูไม่ได้ · ส่วนแคมเปญแสดงครบพร้อมสถานะ
- หน้าคลัง: ค่าเริ่มเป็นการ์ด · ปุ่มสลับอยู่ในหัวหน้า · คลิกการ์ด/รูป = viewer ตัวเดียว · ไม่มีการ์ดสรุป 5 ใบ · ชิปกฎกรองได้
- แผงแคมเปญ: รายการกะทัดรัด · คลิก = viewer
- ลิงก์ `?open=` เปิดแผงถูกแคมเปญ
- ตรวจด้วยตาบนข้อมูลจริง 1440/1024/375 ทั้งสองหน้า + `dwc:design-critic` + `dwc:table-designer` + `dwc:anti-slop-designer` ก่อนบอกว่าเสร็จ
