## แบบ

### 1. มุมกลุ่มเป้าหมาย

- หัวรายการ: ปุ่มสลับ **[แคมเปญ | กลุ่มเป้าหมาย]** แทนปุ่ม "งานวันนี้ / ตัวเลขละเอียด" (ถอดปุ่มนั้น)
- ข้อมูล: ฟังก์ชันใหม่ `audienceRows(cards, range, { brands, roasFromMeta })` ใน `adsCampaigns.js`
  - กลุ่ม = แบรนด์ × แพลตฟอร์ม × `ad_group` ของการ์ดรายวัน · ไม่มี `ad_group` = "ไม่ระบุชุดโฆษณา"
  - ต่อกลุ่ม: spend, leads, cpl, impressions, reach, linkClicks, linkCtr, frequency, spendShare (ของรายการ), campaigns[] (ชื่อ, spend, leads, cpl เรียงค่าแอด), `brandCpl`, `cplRatio`, `decision`
  - แคมเปญหลายชุด → ตัวเลขแบ่งตามชุดจริง (มาจากการ์ดรายวันที่มี ad_group)
  - คำแนะนำ: เกณฑ์เดียวกับแคมเปญ — ผลลัพธ์ < 5 = รอข้อมูล · CPL ≥ 1.5 เท่าของเฉลี่ยแบรนด์ = ควรแก้ · ≤ 0.8 เท่า = ต้นทุนดี · อื่นๆ = ติดตาม (ว่าง)
- แถว: กลุ่มเป้าหมาย (+ แบรนด์ · N แคมเปญ) · ค่าแอด + แถบสัดส่วน · ผลลัพธ์ · CPL เทียบเฉลี่ยแบรนด์ · CTR ลิงก์ · ความถี่ · ควรทำต่อ
- กดแถว = กาง/พับรายชื่อแคมเปญข้างใน (ค่าแอด · CPL) · กดชื่อแคมเปญ = เปิดแผงของแคมเปญนั้น (สลับกลับมุมแคมเปญ)
- ชิปกลุ่ม (ทั้งหมด / ต้องตรวจแก้ / ต้นทุนดี / ...) ใช้ได้ทั้งสองมุม · ชิปที่เป็น 0 ไม่ขึ้น (เหมือนเดิม)

### 2. ตัวเลขชุดเดียวกับหน้า Creative

- `campaignRows` เพิ่ม `linkClicks`, `linkCtr`, `linkCpc` (null เมื่อไม่มี link_clicks) · `delta.frequency` (ช่วงก่อน = impressions ÷ reach ของช่วงก่อน)
- ROAS ระดับแคมเปญ: Meta ไม่เห็นยอด (revenue 0/ไม่รู้) → null (กติกาเดียวกับครีเอทีฟ)
- ตาราง: คอลัมน์ **CTR ลิงก์ · ความถี่** แสดงตลอด
- แผงรายละเอียด:
  - ตัวเลขหลัก: ค่าแอด · ผลลัพธ์ · CPL · **ความถี่** (ต่ำลง = ดีขึ้น)
  - การเข้าถึง: การแสดงผล · เข้าถึง · คลิกลิงก์ · CTR ลิงก์ · CPC ลิงก์ · CTR ทั้งหมด
  - ผลลัพธ์: การซื้อ (Meta) · รายได้ที่ Meta เห็น · ROAS (Meta) ("—" เมื่อไม่มียอด) · %Ads

### 3. สถานะโหลด

- `CampaignsView` ส่ง `loading` (ข้อมูลจริงกำลังโหลด) → ตารางขึ้น "กำลังโหลดแคมเปญ…" แทน "ไม่มีข้อมูลแคมเปญ…" และไม่ขึ้นชิป/จำนวน

### 4. เอาออกจากพื้นผิวหลัก

- บรรทัดความพร้อม ("พร้อมตัดสินใจ · ข้อมูลครบ · รันมา n วัน · ผลลัพธ์ n") → ขึ้นเฉพาะยังตัดสินไม่ได้: "ยังตัดสินไม่ได้ · รออีก N วัน · รอผลลัพธ์อีก N" / "ข้อมูลยังไม่ครบ"
- ป้าย "มีสื่อ N / รอ Creative API" ในหัวส่วนครีเอทีฟ → ถอด (คงป้าย "เสี่ยงล้า N")
- "ที่มาและวิธีคำนวณ": บรรทัดงบแคมเปญ/จังหวะ ขึ้นเฉพาะเมื่อแคมเปญมีงบ · ROAS บรรทัดบอกว่าไม่มียอด = "—"
- ตัวกรองซ่อน: ถอด "เป้าหมาย" และ "งบแคมเปญ" · "สถานะ" ใช้ `campaignDeliveryOf` (รวมแบบตามชื่อ) ตัวเลือก ทั้งหมด / เปิดอยู่ / ปิดอยู่
