# ยึดข้อมูลระบบขายของพี่ทัชทั้งหมด — แผนงาน

**เป้าหมาย:** หน้า ads ใช้ผลจริง เป้า และสถานะข้อมูลจากระบบขายของพี่ทัชเป็นหลัก · ถอดระบบเป้าของเราออก · ไม่มีข้อมูลต้องบอกให้ชัดว่าไม่มีเพราะอะไร

**Spec:** `docs/superpowers/specs/2026-09-16-sales-revenue-bridge.md` (ส่วน "แก้แผน 17 ก.ย.") + ผลสำรวจ inventory 17 ก.ย.

## การตัดสินใจที่ล็อกแล้ว (อาร์ต 17 ก.ย.)

- ทาง B: secret key `marketing_bridge` อ่านของที่มีอยู่แล้ว · ขอเฉพาะคอลัมน์ตัวเลข
- ค่าแอดยึด Meta API ของเรา · ทุกตัวชี้วัดที่ใช้ค่าแอดติดป้าย "คิดจากค่าแอด Meta"
- คนทักแสดงคู่กัน: จากแอด Meta | ทีมขายกรอก (แยก FB / Line)
- %Ads หลัก = `pct_ads_new` (งบแอด ÷ ยอดลูกค้าใหม่) ตามหน้าเป้าหมายของพี่ทัช
- **ทาง ข**: ถอดแท็บเป้าของเราทันที ช่องที่ระบบขายยังไม่มีขึ้น "ยังไม่ตั้งเป้า"
- JK (JUNTAKARN) ทำทีหลัง — ตอนนี้ขึ้น "รอเชื่อมแหล่งข้อมูล" ในส่วนยอดขาย
- ตัด P&L (คีย์อ่านไม่ได้ · ระดับบริษัท) · ค่าแอด CSV / งบประมาณ / AP แสดงสถานะบนหน้า Sync อย่างเดียว

## กติกาเมื่อไม่มีข้อมูล (ใช้ทั้งแอป)

| ข้อความ | เมื่อ |
|---|---|
| ยังไม่มีข้อมูล | แหล่งไม่มีข้อมูลช่วงนั้น (เช่น ได้ออเดอร์ก่อนวันแรกที่มีข้อมูล) |
| ทีมยังไม่กรอก | `inquiry_filled = false` |
| ยังไม่ตั้งเป้า | ไม่มีเป้า หรือเป้ามีแต่ไม่มีช่องนั้น |
| รอเชื่อมแหล่งข้อมูล | แบรนด์ยังไม่มีแหล่งยอดขาย (JK) |
| — (+ เหตุผลเมื่อชี้) | คิดไม่ได้ เช่น ตัวหารเป็น 0 |
